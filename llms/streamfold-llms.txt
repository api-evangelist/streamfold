# Streamfold / Rotel

> Streamfold builds Rotel, a high-performance, resource-efficient OpenTelemetry collector written in Rust. Rotel targets resource-constrained environments — AWS Lambda, serverless functions, and embedded systems — with minimal overhead and fast cold-starts. It is open source under Apache-2.0. In March 2026 Streamfold announced it is joining Cursor. This llms.txt was generated by the API Evangelist enrichment pipeline from the public catalog; Streamfold does not publish an llms.txt of its own.

## Product
- Rotel: OpenTelemetry collector in Rust — https://rotel.dev
- Receivers: OTLP/gRPC, OTLP/HTTP, OTLP/HTTP-JSON, Kafka
- Exporters: ClickHouse, Datadog, AWS X-Ray, Kafka, OTLP
- AWS Lambda extension layer + CloudWatch Lambda forwarder + AWS FireLens log router
- Note: Rotel ingests the standard OpenTelemetry OTLP protocol; it does not expose a proprietary REST/OpenAPI surface.
